# 1.7.0 — Los guardrails funcionan en Codex, Antigravity y OpenCode

- **Fecha**: 2026-11-20 · **Commit**: `d6d09a7` (del espejo agent-plugin-synapse) · **Tipo**: feat
- **Visto en**: diseño ([spec 001 · plugins multi-agente](https://github.com/bypabloc/agent-plugins/tree/synapse-v1.7.0/docs/specs/001-plugins-multi-agente))

## Síntoma

Synapse solo protegía a Claude Code. Al pasar trabajo a Codex, Antigravity u OpenCode, no había hooks: comandos
destructivos, secretos y archivos protegidos quedaban sin control. En Windows, `protect_files` no reconocía ningún
patrón y `.claude/settings.json` o `.codex/config.toml` se editaban sin preguntar.

## Causa

- Los hooks leían y emitían solo el protocolo de Claude Code (nombres de herramientas, JSON y códigos de salida).
- En Windows la ruta resuelta traía `\` y los patrones usaban `/` (`5b56a7b`).

## Cambio

- `hosts.py` normaliza el evento de cada host a `HookEvent`/`Decision` y emite estrictamente el contrato de cada
  uno (failsafe `force_ask` en Antigravity); `dispatch.py` da una sola salida y nunca un exit distinto de 0.
- `patch.py` analiza `apply_patch` multiarchivo de Codex; `approvals.py`: el `ask` de Codex se aprueba una sola vez
  con `scripts/synapse.py approve` (TTY, vencimiento, idempotente por `call_id`).
- Adaptadores: `.codex-plugin` + `adapters/codex/hooks.json`, `.antigravity-plugin` + `hooks.json`, y plugin de
  OpenCode (`block` → `throw`, `ask` → `permission.assert`). `hooks/run-hook.cmd` busca Python 3.10+.
- Reglas nuevas: `self_approval`, `agent_wrapper`, `git clone`/`git -C` fuera del proyecto, configuración de cada
  agente, mínimo de PowerShell y `Set-Content`. Lock portátil y daemon de Laya importable en Windows.

## Prueba

- Golden de Claude Code 1.6.1 (`tests/golden/claude-1.6.1.json`, `test_golden_claude.py`): 162 casos idénticos byte
  a byte, más 17 nuevos.
- `test_hosts.py` (equivalencia por host, contratos, aprobación) con fixtures reales de Codex 0.171.0, agy 1.5.13 y
  OpenCode 2.3.2; 1394 tests. Casos `block_self_approval`, `ask_agent_wrapper_codex_exec`, `ask_codex_config` y
  `block_windows_irm_iex`.
- `test_hosts_e2e.py`: OpenCode 3/3 y Antigravity 3/3; Codex pendiente por el límite de uso de la cuenta.

## Lección

Un golden byte a byte tomado antes de refactorizar es lo que permite portar sin regresiones. Los patrones de rutas
se comparan siempre con `/`, también en Windows.
